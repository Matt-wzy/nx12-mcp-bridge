# NX MCP 使用说明（NX 12 适配版）

让 AI 用自然语言驱动 Siemens NX 12：建模 → 出二维图纸 → 标注公差 → 读回校验 → 编制工艺。

---

## 一、架构（一句话）

`AI（自然语言）` → `MCP 服务器（Python sidecar）` → `命名管道` → `NX 进程内常驻的 C# Loader` → `NXOpen`

- 常驻 Loader 随 NX 启动自动加载，**整场会话都活着**，不需要 Alt+F8 跑 journal。
- 源码位置：
  - C# 侧：`C:\code\nx_mcp_research\NX_MCP-Enhanced\loader\NX_MCP_Loader.cs`
  - Python 侧：`...\src\nx_mcp\`（`certified.py` 工具注册、`loader_bridge.py` 命令映射）
- 部署产物：`C:\Users\matt\.nx_mcp_user\startup\NX_MCP_Loader.dll`

## 二、启动与停止 NX

| 目的 | 做法 |
|---|---|
| 启动 | 后台运行 `cd /c/code/nx_mcp_research && ./nx_start_keepalive.sh` |
| 也可 | 直接从**开始菜单**打开 NX（Explorer 会传 `UGII_USER_DIR`，Loader 正常加载） |
| 重启 NX | `taskkill //IM ugraf.exe //F` → 守护约 15 秒内自动拉起 |
| 彻底停 | 停止那个守护后台任务（界面点停止图标，或 `TaskStop`） |
| 改 C# 代码后 | 停守护 → 复制新 DLL → 重启守护（全自动，无需人工开 UG） |

> **边界**：后台任务能跨回合存活，但**跨不了长时间空闲 / 会话重启**。
> 新会话要用 NX 时，重新拉一次守护即可。

### 二维图纸（写）
`nx_create_drawing_sheet` `nx_create_projected_view` `nx_update_views`
`nx_create_dimension`（两对象线性尺寸，带公差）
`nx_create_angle_dimension`（**角度尺寸**：两直线边夹角，斜面/锥面/倾角标注；
边须共点或相交，arc=minor|major 选劣/优弧（读回 value 直接是度数，实测
129.806/230.194 与理论一致）。注意：边的夹角要在**能看到斜度的视图**里量——
投影后平行的两边只会得到 0°/360°）
`nx_create_diameter_dimension`（**直径**，轴类必需）
`nx_create_radius_dimension`（**半径**，圆角/圆弧）
`nx_create_note`（技术要求 / 工序文字，`|` 换行。**中文必须传 `note_font="chinesef"`**，
默认字体无中文字形渲染成空心方块。可选指引线：`leader_view_id` + `leader_body_id` +
`leader_edge_index` 三者齐传，箭头落到视图内该边中点——工序说明指向加工面
（"精铣此面 留磨量0.3"）全靠它；带指引线时 NX 类型自动从 Note 变成 Label）
`nx_create_roughness`（表面粗糙度符号，数值写入符号的 a1 位，如 `1.6` / `3.2`；
可选指引线同 note（GB/T 131 加工面指向））
`nx_create_centerline`（**对称中心线**：传视图 + 圆柱面索引，轴线自动画进视图；
轴类零件出图必需。用 `nx_list_faces` 找圆柱面，选**轴线在视图平面内**的面——
如正视图里的轴身；俯视图里端面朝上的孔画不出有用的轴线）
`nx_create_title_block`（放置标题栏，位置为图纸坐标；建议 A3 横放取 `340,5`）
`nx_create_section_view`（**剖视图**：传父视图 + 剖切线两端点（图纸坐标）+ 放置点，
UFUN CreateSimpleSxview。step 方向默认沿剖切线、arrow 默认垂直（视向）——
**二者平行 NX 会报"截面线零矢量错误"**。视向默认指向剖切线 x1,y1→x2,y2 行进方向的左侧，
可传 `arrow_dx/dy` 翻转；`scale` 相对父视图）
`nx_delete_view`（**删图纸视图**：按 nx_list_drafting_views 的索引/名称/ID 删；
剖视图会连带删剖切线。改图前先删旧视图，NX 没有回收站，删前核对）
`nx_add_section_segment`（**阶梯剖**：向 nx_create_section_view 建好的剖视图剖切线
追加一刀（图纸坐标两点），NX 自动生成转折段并更新剖视图；多孔零件工艺图常用。
连续追加多刀即可阶梯式剖切）
`nx_create_datum_symbol`（**基准符号**：GD&T 基准字母框，如 [A]；字母 1-2 字符自动大写，
位置为图纸坐标。可选指引线同 note——箭头落到被测要素边上（PDF 实测带 GB 三角形
基准连接符）；不传指引线则独立放置，放在尺寸线延长线或被测要素附近；
与形位公差标注配套使用：基准没有公差框引用就是孤立符号）
`nx_create_gdt_frame`（**形位公差框**：GD&T 特征控制框，GB/T 1182。可选指引线同 note
——箭头指向被测要素边。特征名可用中文
（直线度/平面度/圆度/圆柱度/线轮廓度/面轮廓度/倾斜度/垂直度/平行度/位置度/
同轴度/对称度/圆跳动/全跳动）或英文枚举名；`tolerance` 为公差值文本如 `0.02`；
`datum_primary/secondary/tertiary` 填基准字母；`zone_shape=diameter` 加 Ø（轴/孔
公差带）；`material_modifier=mmc/lmc` 加 Ⓜ/Ⓛ。独立放置无指引线，放在被测尺寸
附近，与 nx_create_datum_symbol 配套）

### 部件属性（标题栏的内容来源）
`nx_set_attribute`（设属性：`<名称> <值>`，值可含空格）
`nx_list_attributes`（读回全部属性，返回**结构化** `attributes` 字典——
它同时是 `nx_export_process_card` 的数据源）

`nx_export_process_card <路径> [text|csv]`（**工序卡导出**，工艺卡片模板：
用 `nx_set_attribute` 按工序设属性，键为 `OP<序号>_<字段>`，如
`OP10_NAME`（工序名）/ `OP10_CONTENT`（内容）/ `OP10_MACHINE` 或 `OP10_设备` /
`OP10_FIXTURE`（装夹）/ `OP10_TOOL`（刀具）/ `OP10_CUTTING`（切削参数）/
`OP10_TIME`（工时）；零件头信息用 名称/图号/材料/比例。工序按**数字**排序
（OP5 < OP10 < OP100），中英字段名混用都认；text 出可读卡片，csv 出 Excel 表。
消息里会报 typo 字段和缺 名称/内容/设备 的工序）

> **关键理解**：标题栏的格子通常**引用部件属性**显示，
> 所以要"填标题栏"其实是 `nx_set_attribute 名称 阶梯轴` 这样设属性，
> 而不是往格子里写死文字。常用名：名称 / 图号 / 材料 / 设计 / 审核 / 比例 / 单位。
`nx_delete_annotation`（删除标注：按 ID/名称，或 `note:0` / `dim:1` / `gdt:0` / `rough:0`）
`nx_export_pdf`（导出 PDF：`<路径.pdf> [图纸页名|ALL]`；**ALL = 全部图纸页导出到
一个多页 PDF**（Append 逐页追加实现，NX12 原生多页导出不可用），全套图纸一次出）
`nx_export_dwg`（**DXF/DWG 导出**：进程外跑官方 dxfdwg translator，
NX 内 Commit() 从不 spawn 它；部件先自动落盘。钣金下料/激光切割/套料要 .dxf）

### 三维查询
`nx_measure_distance`（**查询**两棱边间的最小距离，返回数值+最近点，不生成标注）
`nx_measure_angle`（**查询**两直线边夹角：返回 [0,180] 角与锐角补角；装夹/工序定位常用。边必须为直线，索引来自 nx_list_edges）
`nx_mass_properties`（**查询**质量属性：体积 mm³ / 表面积 mm² / 重心 mm / 质量 kg；
质量 = 体积 × 密度，默认钢 7830 kg/m³，可传实际材料密度。材料定额、毛坯选用、吊装/夹具重心计算常用。
传 `per_body=true` 时额外按体逐个返回 `bodies` 列表——多腔模/多工序件要每件单独的值）

### 毛坯生成（材料定额第一步，NX12 新增）
`nx_create_stock <box|cyl> [body_id] [allowance=2] [axis=auto] [dia=0]
[length=0]`——把指定体的包围盒包成机加工毛坯新体（注册为 BODY_<n>）：
box=长方体每侧加 `allowance`；cyl=沿 `axis` 的圆柱棒料，直径盖截面
bbox **对角线**（方形断面安全、圆轴偏保守——传 `dia=` 指定标准棒料直径
则不再加径向余量），`length=` 同理覆盖长度（不加轴向余量）。axis 缺省
auto=最长 bbox 维（并列优先 z，车削轴惯例）。返回毛坯体积、零件体积、
**材料利用率 pct**（part/stock，材料定额直读）和 bbox 回显。配合
`nx_mass_properties`（零件质量）用。实测三种模式体积与解析解精确一致。

### 表格注解（孔表/参数表上图纸，NX12 新增）
`nx_create_table <pos_x> <pos_y> <cells> [col_width=20] [row_height=6]
[header=False] [font=] [allow_cjk=False]`——在当前图纸页创建表格注解。
`cells` 行分隔 `|` 列分隔 `,`（如 `"NO,DIA,DEPTH|1,8,15|2,10,20"`），
可含空格但不能有换行；行列数必须整齐（1..30 列 1..50 行）；NX 会自动
剥离创建时自带的默认模板格（否则网格尺寸不对）。`header=True` 首行
标记表头（NX 默认 header_location=Below，表头渲染在**表尾**）。
**限制**：NX12 仅 ASCII 格文可渲染——非 ASCII 格文默认拒绝
（NX_CJK_CELL_TEXT），`allow_cjk=True` 强行（存对但渲染成方块）；
中文标签用 `nx_create_note` 在格位上方覆盖标注。`font=` 设部件注释
默认字体（对之后新建的 .NET 注释生效，不改变表格格渲染）。响应回读
首格文本自校验。数据源配合 `nx_list_holes` / `nx_export_bom_csv`。

### 孔表（钻孔工序/孔位明细，NX12 新增）
`nx_list_holes [body_id]`——**模型侧孔扫描**：把体上的圆柱壁逐个分类
`kind`（hole=轴心处是孔腔 / boss=轴心处是材料即轴/凸台）、直径、深度、
轴心位置 x/y/z（模型空间 mm，z=壁高中点，盲孔读作 孔口 z+深度/2）。
解析圆柱面（UF type 16）和本项目 nx_hole/草图拉伸减除产生的参数化拉伸壁
（type 20）**都能识别**（采样圆柱拟合路线）；锥面/钻孔尖、倒圆（环面）、
球面、平面自动排除并在消息里按类型计数。`full_wall=false` 标记交叉孔/
铣开等非整圆壁——几何仍准但位置需人工复核。只读。

`nx_export_hole_table_csv <路径>`——孔表 CSV（列：hole_no, dia_mm, x_mm,
y_mm, z_mm, depth_mm, face_index；UTF-8 BOM，Excel 直开）。只保留 kind=hole
行，凸台不入表；消息里给按直径汇总（如 d8x4 d10x1）。无孔壁时报
NX_EMPTY_HOLE_TABLE。典型流程：`nx_hole`/建模打孔 → `nx_export_hole_table_csv`
出孔位明细 → 配合 `nx_export_process_card` 编钻孔工序。

> 注：这是**模型侧**孔表（读几何），绕开了 NX 制图侧 HoleTableBuilder
> 的"视图孔对象"墙（五轮探明受阻，见受阻项记录第 8 节）。孔口倒圆、
> 沉头/锪平等非圆柱特征段不单列入表，螺纹底孔按实际直径列。

`nx_list_drawing_sheets` `nx_list_drafting_views`
`nx_list_dimensions`（尺寸值 + 上下公差 + 公差类型）
`nx_list_annotations`（NOTE / GDT 形位公差 / ROUGH 粗糙度）

### 草图读取 / 尺寸改值 / WAVE 链接（NX12 适配新增）
`nx_read_sketch <sketch_name>`——把（含外部绘制的）草图按**草图局部坐标**导出：
返回所在平面（XY/XZ/YZ）、原点与坐标轴，以及每条曲线
（line `{a,b}` / arc `{c,r,a1,a2}` / circle `{c,d}`）。
用于在别的部件里忠实复刻轮廓，或做工艺路线前的几何交接。

`nx_set_dimension_value <target_size> <new_value>`——把最接近
target_size 的关联尺寸的**显示值**强制改为 new_value
（中差标注场景：计算值 99.96 显示成 100）。返回文本里记录
实际走通的改值通道。

`nx_create_wave_link <source_master> <target_part> [body_index] [assoc=1]`
——**WAVE 几何链接器**：源件作装配根，目标件作下游组件，把源实体
链入目标工序件。默认**固定时间戳记**（提取几何快照，不随主模型更新，
符合"主模型 → 各工序件自上而下冻结"），末尾加 `assoc=1` 才是实时关联。

  - 目标件已存在会被**删除重建**；路径不能含空格
  - 单位必须与主模型一致（内部固定公制；UF_PART_METRIC=1）
  - ⚠️ 若主模型里挂过同名组件（哪怕指向的文件已不存在），NX 会话的
    部件名注册表会**永久**记住它，Loader 已自动卸载残留实例；
    但若反复报"文件已存在/部件已存在"，给目标件换个名字即可
  - `position` 参数（x/y/z 摆放偏移）为保留项，当前显式报错
    （变换矩阵未经几何验证前不开放，详见 NX_MCP_Loader.cs 的
    CreateWaveLink 注释）

### 装配 / BOM（工艺路线表数据源，NX12 新增）
`nx_list_assembly`——把活动部件的装配树**拍平**成逐实例行：
`level`（1=顶层）/ 实例名 / 显示名 / 子件 .prt 路径（已加载时）/ 子件数 /
`qty`（同原型件全装配实例总数）/ `attributes`（**跨部件读子件属性**：
材料/图号等字符串属性字典，子件在会话中加载时可用）。
这是 BOM/明细表的原始数据。

`nx_export_bom_csv <路径>`——直接把装配树导出为 CSV 明细表
（列：level, name, display_name, part_path, children, qty, material, drawing_no；
material/drawing_no 自动从子件属性挑：MATERIAL/NX_Material/材料/材质、
DB_PART_NO/图号/PART_NO/DWG_NO/件号；UTF-8 BOM，
Excel 直接打开中文名不乱码）。非装配部件会报 NX_EMPTY_ASSEMBLY。
典型流程：`nx_create_wave_link` 建好工序件装配 → `nx_export_bom_csv` 出表。

> **注意**：`nx_create_wave_link` 后 loader 当前件=新子件，立即 `nx_set_attribute`
> 设材料/图号再 `nx_save_part`，子件属性才随子件落盘；另外 NX 会把用户属性
> `MATERIAL` 改名为 `NX_Material`（导出时两种写法都认）。

### 爆炸视图 / 装配出图（NX12 新增）
`nx_refset_add_bodies [name=MODEL]`——**把全部实体加入引用集**（缺省新建
MODEL）。子件体不在引用集里时，`nx_add_component` 装进装配后组件显示为空
（出图空白）。**在子件上调用后保存**，再往装配里加。装配打开时子件几何
自动全量加载（LoadFully，无需额外操作）。

`nx_create_explosion [name]` / `nx_explode_component <爆炸名> <组件名> dx dy dz`
/ `nx_unexplode_component` / `nx_list_explosions`——**爆炸视图状态**（装配
工序卡配图）。组件按实例名（nx_list_assembly 的 name，大小写不敏感）平移，
返回值回显 NX 存储的平移量自校验。`nx_create_projected_view` 加
`explosion=<名>` 可挂接到图纸视图——⚠️ NX12 实测挂接成功但**偏移不渲染**
（组件本体渲染正常，见受阻项第 11 节）；爆炸状态保存在部件里，交互打开
NX 可见。

`nx_create_id_symbol`（**球标/ID 符号**：circle/tri/square/hexagon/roundbox 等 11 种，
upper_text 进上槽、lower_text 进下槽；装配工序图的零件序号气泡，
与 BOM 导出配套——球标序号和明细表行对得上）

测试脚本：`examples/test_wave_link.py`（基本链路）、
`examples/test_wave_placement.py`（摆放，待开放）、
`examples/ping_status.py`（探活）、`examples/unpoison_master.py`
（清理主模型里的坏组件引用）。

## 四、典型流程模板

### 建模
```
建部件 → 建草图 → 画草图元素 → 完成草图 → 拉伸/回转 → 保存
```
回转体（轴、盘）：画**半剖面**折线 → `nx_revolve` 绕轴线 360°。

### 出二维图纸
```
建图纸页（自动带基础视图）→ 投影视图 → 更新视图
→ 直径/半径/线性标注（带公差）→ 技术要求文字 → 保存
```

### 读已有图纸
```
打开部件 → 列图纸页 → 列视图 → 读尺寸公差 → 读文字/形位公差/粗糙度
```

### 编工艺
```
每道工序建一张图纸页 → 每页写本工序目标/设备/切削参数 → 输出工艺流程表
```

## 五、已知坑（务必遵守）

1. **body_id 有两套 ID 空间**
   `nx_list_bodies` 显示的是 NX 日志标识（如 `EXTRUDE(1)`），但命令只认
   建模时返回的内部 ID（如 `BODY_1`）。**必须串联命令返回的 body_id**。

2. **边索引在不同部件实例间不稳定**
   同一个模型重建后，边编号会变（实测 r15 的边一次是 2、一次是 0）。
   **不要硬编码索引**，应先 `nx_list_edges` 再按半径/长度/坐标筛选。
   （回转体的 `start` z 值即半径，可据此自动定位。）

3. **命名管道必须重试**
   服务端单实例，两次命令间有空窗。用官方 `ctypes + WaitNamedPipe` 重试方式；
   Python 内置 `open()` 第 2 条起会报 `Errno 22`。

4. **图纸名 / 视图名不能含空格**（管道按空格分词）。

5. **note 文本用 `|` 换行**；文字放在参数最后，可含空格。

6. **传坐标要用 `{"x":..,"y":..}` 字典**，传 list 会报
   `'list' object has no attribute 'x'`。

7. **重复打开同一部件**：已修复（路径分隔符归一化）。但打开失败会读到
   **上一个部件的陈旧数据**，务必看返回值确认。

8. **CGM 弹窗已修**：含多张图纸页时保存会弹"保存 CGM"模态框把 NX 卡死，
   已在保存前关闭 `SaveOptions.DrawingCgmData`。

9. **`create_block` 不带显式部件时会写进 NX 安装目录**（且可能静默失败）。
   务必先 `nx_create_part` 指定工作区路径。

10. **改代码后必须重启 NX** 才生效（DLL 被占用无法覆盖）。

11. **中文 note 必须 `note_font="chinesef"`**：默认注释字体（blockfont/Arial）
    无中文字形，PDF 渲染成空心方块。chinesef 是 NX 自带 CJK 制图字体，
    Loader 会按需 `FontCollection.AddFont` 加进部件字体表（实测 PDF 正常）。
    未知字体名会报错并列出当前字体表，照抄即可。
