# NX MCP 使用说明（NX 12 适配版）

让 AI 用自然语言驱动 Siemens NX 12：建模 → 出二维图纸 → 标注公差 → 读回校验 → 编制工艺。

---

## 一、架构（一句话）

`AI（自然语言）` → `MCP 服务器（Python sidecar）` → `命名管道` → `NX 进程内常驻的 C# Loader` → `NXOpen`

- 常驻 Loader 随 NX 启动自动加载，**整场会话都活着**，不需要 Alt+F8 跑 journal。
- 源码位置：
  - C# 侧：`C:\code\nx_mcp_research\NX_MCP-Enhanced\loader\NX_MCP_Loader.cs`
  - Python 侧：`...\src\nx_mcp\`（`certified.py` 工具注册、`loader_bridge.py` 命令映射）
- 部署产物：`C:\Users\matt\.nx_mcp_user\startup\NX_MCP_Loader.dll`

---

## 二、启动与停止 NX

| 目的 | 做法 |
|---|---|
| 启动 | 后台运行 `cd /c/code/nx_mcp_research && ./nx_start_keepalive.sh` |
| 也可 | 直接从**开始菜单**打开 NX（Explorer 会传 `UGII_USER_DIR`，Loader 正常加载） |
| 重启 NX | `taskkill //IM ugraf.exe //F` → 守护约 15 秒内自动拉起 |
| 彻底停 | 停止那个守护后台任务（界面点停止图标，或 `TaskStop`） |
| 改 C# 代码后 | 停守护 → 复制新 DLL → 重启守护（全自动，无需人工开 UG） |

> **边界**：后台任务能跨回合存活，但**跨不了长时间空闲 / 会话重启**。
> 新会话要用 NX 时，重新拉一次守护即可。

## 三、工具清单（53 个）

### 部件与查询
`nx_status` `nx_create_part` `nx_open_part` `nx_save_part` `nx_close_part`
`nx_list_bodies` `nx_list_edges` `nx_list_faces` `nx_list_features` `nx_list_sketches`
`nx_fit_view` `nx_undo` `nx_release` `nx_export_step`

### 草图与建模
`nx_create_sketch` `nx_sketch_line` `nx_sketch_rectangle` `nx_sketch_circle` `nx_sketch_arc`
`nx_finish_sketch` `nx_extrude` `nx_revolve` `nx_hole` `nx_counterbore_hole`
`nx_countersink_hole` `nx_shell` `nx_edge_blend` `nx_chamfer` `nx_unite`
`nx_mirror` `nx_linear_pattern` `nx_circular_pattern`

### 二维图纸（写）
`nx_create_drawing_sheet` `nx_create_projected_view` `nx_update_views`
`nx_create_dimension`（两对象线性尺寸，带公差）
`nx_create_diameter_dimension`（**直径**，轴类必需）
`nx_create_radius_dimension`（**半径**，圆角/圆弧）
`nx_create_note`（技术要求 / 工序文字，`|` 换行）
`nx_create_roughness`（表面粗糙度符号，数值写入符号的 a1 位，如 `1.6` / `3.2`）
`nx_create_title_block`（放置标题栏，位置为图纸坐标；建议 A3 横放取 `340,5`）

### 部件属性（标题栏的内容来源）
`nx_set_attribute`（设属性：`<名称> <值>`，值可含空格）
`nx_list_attributes`（读回全部属性）

> **关键理解**：标题栏的格子通常**引用部件属性**显示，
> 所以要"填标题栏"其实是 `nx_set_attribute 名称 阶梯轴` 这样设属性，
> 而不是往格子里写死文字。常用名：名称 / 图号 / 材料 / 设计 / 审核 / 比例 / 单位。
`nx_delete_annotation`（删除标注：按 ID/名称，或 `note:0` / `dim:1` / `gdt:0` / `rough:0`）
`nx_export_pdf`（导出 PDF：`<路径.pdf> [图纸页名]`，指定页会先显示该页）

### 三维查询
`nx_measure_distance`（**查询**两棱边间的最小距离，返回数值+最近点，不生成标注）

### 二维图纸（读）
`nx_list_drawing_sheets` `nx_list_drafting_views`
`nx_list_dimensions`（尺寸值 + 上下公差 + 公差类型）
`nx_list_annotations`（NOTE / GDT 形位公差 / ROUGH 粗糙度）

### 草图读取 / 尺寸改值 / WAVE 链接（NX12 适配新增）
`nx_read_sketch <sketch_name>`——把（含外部绘制的）草图按**草图局部坐标**导出：
返回所在平面（XY/XZ/YZ）、原点与坐标轴，以及每条曲线
（line `{a,b}` / arc `{c,r,a1,a2}` / circle `{c,d}`）。
用于在别的部件里忠实复刻轮廓，或做工艺路线前的几何交接。

`nx_set_dimension_value <target_size> <new_value>`——把最接近
target_size 的关联尺寸的**显示值**强制改为 new_value
（中差标注场景：计算值 99.96 显示成 100）。返回文本里记录
实际走通的改值通道。

`nx_create_wave_link <source_master> <target_part> [body_index] [assoc=1]`
——**WAVE 几何链接器**：源件作装配根，目标件作下游组件，把源实体
链入目标工序件。默认**固定时间戳记**（提取几何快照，不随主模型更新，
符合"主模型 → 各工序件自上而下冻结"），末尾加 `assoc=1` 才是实时关联。

  - 目标件已存在会被**删除重建**；路径不能含空格
  - 单位必须与主模型一致（内部固定公制；UF_PART_METRIC=1）
  - ⚠️ 若主模型里挂过同名组件（哪怕指向的文件已不存在），NX 会话的
    部件名注册表会**永久**记住它，Loader 已自动卸载残留实例；
    但若反复报"文件已存在/部件已存在"，给目标件换个名字即可
  - `position` 参数（x/y/z 摆放偏移）为保留项，当前显式报错
    （变换矩阵未经几何验证前不开放，详见 NX_MCP_Loader.cs 的
    CreateWaveLink 注释）

测试脚本：`examples/test_wave_link.py`（基本链路）、
`examples/test_wave_placement.py`（摆放，待开放）、
`examples/ping_status.py`（探活）、`examples/unpoison_master.py`
（清理主模型里的坏组件引用）。

## 四、典型流程模板

### 建模
```
建部件 → 建草图 → 画草图元素 → 完成草图 → 拉伸/回转 → 保存
```
回转体（轴、盘）：画**半剖面**折线 → `nx_revolve` 绕轴线 360°。

### 出二维图纸
```
建图纸页（自动带基础视图）→ 投影视图 → 更新视图
→ 直径/半径/线性标注（带公差）→ 技术要求文字 → 保存
```

### 读已有图纸
```
打开部件 → 列图纸页 → 列视图 → 读尺寸公差 → 读文字/形位公差/粗糙度
```

### 编工艺
```
每道工序建一张图纸页 → 每页写本工序目标/设备/切削参数 → 输出工艺流程表
```

## 五、已知坑（务必遵守）

1. **body_id 有两套 ID 空间**
   `nx_list_bodies` 显示的是 NX 日志标识（如 `EXTRUDE(1)`），但命令只认
   建模时返回的内部 ID（如 `BODY_1`）。**必须串联命令返回的 body_id**。

2. **边索引在不同部件实例间不稳定**
   同一个模型重建后，边编号会变（实测 r15 的边一次是 2、一次是 0）。
   **不要硬编码索引**，应先 `nx_list_edges` 再按半径/长度/坐标筛选。
   （回转体的 `start` z 值即半径，可据此自动定位。）

3. **命名管道必须重试**
   服务端单实例，两次命令间有空窗。用官方 `ctypes + WaitNamedPipe` 重试方式；
   Python 内置 `open()` 第 2 条起会报 `Errno 22`。

4. **图纸名 / 视图名不能含空格**（管道按空格分词）。

5. **note 文本用 `|` 换行**；文字放在参数最后，可含空格。

6. **传坐标要用 `{"x":..,"y":..}` 字典**，传 list 会报
   `'list' object has no attribute 'x'`。

7. **重复打开同一部件**：已修复（路径分隔符归一化）。但打开失败会读到
   **上一个部件的陈旧数据**，务必看返回值确认。

8. **CGM 弹窗已修**：含多张图纸页时保存会弹"保存 CGM"模态框把 NX 卡死，
   已在保存前关闭 `SaveOptions.DrawingCgmData`。

9. **`create_block` 不带显式部件时会写进 NX 安装目录**（且可能静默失败）。
   务必先 `nx_create_part` 指定工作区路径。

10. **改代码后必须重启 NX** 才生效（DLL 被占用无法覆盖）。

## 六、排障

| 现象 | 先看这里 |
|---|---|
| 管道连不上 | ① NX 是否运行 ② 是否由守护启动（环境变量是否带到）③ 看日志 |
| Loader 日志 | `%USERPROFILE%\NX_MCP_WORKSPACE\nx_mcp_loader.log`（含命令、返回值、异常堆栈） |
| 分层验证 | `python pipe_smoke.py ping nx_status` —— 不依赖 Agent，直接测桥 |
| DLL 是否真更新 | 大小可能因 **512 字节对齐**不变；字符串按 **UTF-16** 存、方法名按 **UTF-8** 存，两种都要查 |

## 七、尚未支持

- 真实螺纹（上游项目也不支持，用修饰螺纹或注释替代）
- 中心线（自动中心线 Builder 提交时报 NX 状态 1175325，未解决）
- DWG/DXF 图纸导出（`Commit()` 成功但不出文件，已试 4 轮未解决；PDF 已支持）
- 剖视图（`SectionLineBuilder` 在 NX10 已弃用，替代方案未找到）
- 局部放大（始终报"用于定义边界的点不能相同"，已试 6 轮）
- 图框边框线（`NXOpen.Diagramming` 是图表应用而非制图应用，套不上；
  可能只能靠图纸模板/格式解决）
- 批量导出多张图纸页到**一个** PDF（目前一次一页；多页请循环调用后自行合并）
- 装配（添加组件、约束）
- 剖视图 / 局部放大 / 中心线 / 图框标题栏
- 扫掠、放样
